# Tower of Hanoi (SWI-Prolog + JavaScript)

Web game with 4 modes (Easy, Hard, Difficult, Nightmare) and a Random Mode.
Single player and multiplayer (2 to 4 players).

## Requirements
- SWI-Prolog (https://www.swi-prolog.org)
- Chrome or any browser

## How to run
1. Download `towerofhanoi.pl`
2. Open a terminal in the same folder
3. Run: `swipl towerofhanoi.pl`
4. Open http://localhost:8080/ if the browser does not open by itself

## Features
- Prolog server handles the rules, move counting, ranking and leaderboard
- Hover mode select with live demo, Japanese themes per mode
- Mouse-only controls, undo/restart (single player only), pause, settings
